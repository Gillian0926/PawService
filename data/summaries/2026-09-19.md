- **Large Language Models as Falsifiers for Cyber-Physical Systems** — 提出 LLM-Falsifier，把 CPS 规格（STL）证伪化为鲁棒度最小化，并给 LLM 暴露自然语言输入输出名、输出轨迹与关键时间证人等语义信息以提升采样效率；在 ARCH-COMP 基准 21 条规格中，按找到反例所需平均仿真次数计在 14 条上优于现有工具。。[arXiv:2609.20752](https://arxiv.org/abs/2609.20752)
- **Q&A on Any Spreadsheet Requires Interpreting Its Grid Structure** — 提出基于单元格角色标注把任意电子表格拆成可解释 chunk 的框架，用于 LLM 驱动的 RAG 问答，优于现有方法但存在硬天花板；论证二维表格的连续关系与无限角色无法被有限类别分类完全刻画，主张应发展降维技术直接把 2D 表格展平为 1D 文本。。[arXiv:2609.20732](https://arxiv.org/abs/2609.20732)
- **Spotlights: Discovering Improvement Opportunities in Software Repositories** — 提出优化机会发现系统 Spotlights，在仓库级通过逻辑映射、多轮智能体评审与可选研究链接识别值得改进的源码区域并解释与目标关系；三个案例中找回 9 个专家目标中的 7 个，实施一个发现使页面处理端到端耗时降低 10.6%。。[arXiv:2609.20446](https://arxiv.org/abs/2609.20446)
- **Assessing the Construct Validity of Object-Oriented, Class-Level Code Quality Metrics** — 用探索性与验证性因子分析考察面向对象类级代码质量度量的构念效度：在 Apache Maven 上提取并验证 24 个度量对应内聚、耦合、规模、继承六类构念，10 个不属任何已知维度的度量被移除；支持 24 个度量的构念效度并揭示耦合与继承为多维构念。。[arXiv:2609.20411](https://arxiv.org/abs/2609.20411)
- **AdaRepair-Mem: Adaptive Experience Orchestration for Repository-Level Program Repair** — 提出自适应经验编排的程序修复框架 AdaRepair-Mem，用覆盖感知检索（同仓库不足时回退跨仓库/修复类型记忆）、质量感知选择与阶段感知路由分别应对记忆不均衡、冗余与阶段错位；在 SWE-Bench-Lite 与 Verified 上改善欠覆盖仓库修复并降低噪声检索。。[arXiv:2609.20130](https://arxiv.org/abs/2609.20130)
- **HapCiD: Detecting API-related Compatibility Issues in OpenHarmony Apps** — 提出开源工具 HapCiD，针对 OpenHarmony 新语言 ArkTS 与行为模型缺失自动检测 API 兼容性问题；应用于 4,478 个应用，在 163 个应用中检出 2,040 个兼容性问题，准确率 100%。。[arXiv:2609.20099](https://arxiv.org/abs/2609.20099)
